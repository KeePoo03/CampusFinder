# CampusFinder — Telegram-бот бюро находок

Учебный Telegram-бот на Python для поиска потерянных и найденных вещей в университете.

Пользователь создаёт объявление «Потерял» или «Нашёл»: указывает название вещи, место и **по желанию прикрепляет фотографию**. Другие пользователи могут просмотреть объявления и найти нужную вещь по названию или месту.

## Команды

| Команда | Что делает |
| --- | --- |
| `/start` | Показывает список команд |
| `/lost` | Создать объявление о потерянной вещи |
| `/found` | Создать объявление о найденной вещи |
| `/skip` | Опубликовать объявление без фотографии |
| `/all` | Посмотреть активные объявления и фотографии |
| `/search телефон` | Поиск по названию или месту |
| `/mine` | Посмотреть свои объявления |
| `/close 2` | Закрыть своё объявление №2 |
| `/cancel` | Отменить заполнение |

## Как запустить

1. Установить Python и выполнить `pip install -r requirements.txt`.
2. Создать бота через [@BotFather](https://t.me/BotFather).
3. Скопировать `config.example.py` в `config.py` и вставить свой Telegram-токен.
4. Запустить `python bot.py`.
5. Написать `/start` своему боту в Telegram.

Объявления сохраняются в `data/ads.txt`. Фотографии не скачиваются на компьютер: в файле хранится только `file_id`, который Telegram выдаёт для изображения. Старые объявления без фото тоже читаются.

**Важно:** `config.py` и папка `data/` не должны попадать в GitHub. Добавьте их в `.gitignore`, если их там ещё нет. После публикации на GitHub бот не запускается автоматически — программу необходимо запустить отдельно.
